### Анализ предметной области
В данном разделе я разбираю основные бизнес-правила рассматриваемой предметной области (маркетплейс)

У **пользователя**:
- может быть 0-N заказов
- всегда 1 корзина
- Может быть продавцом (0/1)
- Должен быть хоть 1 адрес
- Может быть 0-N избранных товаров
У **продавца**:
- Он должен быть пользователем
- Должно быть 0-N товаров
У **корзины**:
- Может быть 0-N товаров в корзине 
- должен быть 1 пользователь
У **товаре в корзине**:
- Должна быть 1 корзина
- Соответсвует 1 товару
У **товара**:
- должен быть 1 продавец
- может быть 0-N категорий
- Может быть товаром в корзине у многих пользователей
- Может быть товаром в заказе у многих пользователей
- Может быть избранным у 0-N пользователей
У **категории**:
- должно быть 1-N товаров
- Может быть 0..N категорий
У **заказа**:
- должен быть 1 пользователь
- может быть 1-N товаров в заказе
- должен быть 1 адрес доставки
У **товары в заказе**:
- Должен быть 1 заказ
- Соответствует 1 товару
У **доставки**:
- Должен быть 1 адрес
- Должен быть 1 заказ
У **адреса**:
- Может быть 0-N доставок
- Должен быть у 1 пользователя
У **избранных товаров**:
- Может быть 1 пользователь
- Может соответствовать 1 товару

### Приведение схемы в 3НФ, определение первичных ключей, создание таблицы в postgreSQL

В данном разделе полученная в 2-ом разделе ER-диаграмма будет преобразована в 3НФ, для этого определим первичные ключи, а для удобства работы будем сразу использовать удобный инструмент работы с ER-диаграммами, встроенный прямо в pgAdmin 4 - ERD tool. 

Для всех таблиц я выбрал суррогатный первичный ключ, так как естественный в данной предметной области не нужен. Бизнес-логика маркетплейса - это одна из самых изменчивых сред. Любой естественный идентификатор, который сегодня кажется незыблемым, завтра изменится из-за новых законов, слияния компаний, ошибок ввода или выхода на новые рынки. Но во избежание ошибок, я добавил несколько ограничений уникальности. Которые будут выступать и как предотвращение дубликатов, так и вторичным естественным ключом при необходимости.

Сделал я уникальное ограничение для:
- пользователя (по email и телефону)
- продавцу (по инн)
- Адресу (По городу,улице,этажу,квартире)
- Товару (по артикулу)
- Категории (По родителю и названию)
- товарам в заказе, корзине и избранным (по id заказа/корзины/юзера + id товара)
- Заказу (По публичному номеру заказа)
- И доставке (по трекинговому-номеру)

### Словарь данных

 1. Таблица: user (Пользователи)

| Имя столбца | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                    |
| ----------- | ---------- | ------------------------- | -------------------------------------------------------- |
| user_id     | bigint     | PK, NOT NULL              | Уникальный идентификатор пользователя (суррогатный ключ) |
| user_name   | text       | NOT NULL                  | ФИО или имя пользователя                                 |
| user_phone  | text       | UNIQUE, NOT NULL          | Номер телефона для связи и авторизации                   |
| user_email  | text       | UNIQUE, NOT NULL          | Электронная почта для чеков и уведомлений                |

 2. Таблица: seller (Продавцы)

| Имя столбца | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                         |
| ----------- | ---------- | ------------------------- | ------------------------------------------------------------- |
| seller_id   | bigint     | PK, NOT NULL              | Уникальный идентификатор продавца                             |
| user_id     | bigint     | FK, UNIQUE, NOT NULL      | Ссылка на аккаунт пользователя (Связь 1:1). ON DELETE CASCADE |
| inn         | text       | UNIQUE, NOT NULL, CHECK   | ИНН продавца. Проверка: длина строго 10 или 12 символов       |

 3. Таблица: category (Категории товаров)

| Имя столбца   | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                            |
| ------------- | ---------- | ------------------------- | ---------------------------------------------------------------- |
| category_id   | bigint     | PK, NOT NULL              | Уникальный идентификатор категории                               |
| category_name | text       | NOT NULL                  | Название категории (например, "Электроника")                     |
| parent_id     | bigint     | FK                        | Ссылка на родительскую категорию (Иерархия). ON DELETE NO ACTION |
| (Table Level) | -          | UNIQUE                    | Уникальная комбинация parent_id и category_name                  |

 4. Таблица: Product (Товары)

| Имя столбца         | Тип данных | Ограничения (Constraints) | Назначение (Описание)                          |
| ------------------- | ---------- | ------------------------- | ---------------------------------------------- |
| product_id          | bigint     | PK, NOT NULL              | Уникальный идентификатор товара                |
| product_name        | text       | NOT NULL                  | Название товара                                |
| article             | integer    | UNIQUE, NOT NULL          | Артикул товара (уникальный номер в системе)    |
| product_description | text       | -                         | Текстовое описание товара                      |
| product_picture     | text       | NOT NULL                  | Ссылка на изображение товара                   |
| product_price       | integer    | NOT NULL, CHECK           | Текущая стоимость товара. Проверка: цена > 0   |
| seller_id           | bigint     | FK, NOT NULL              | Ссылка на продавца товара. ON DELETE CASCADE   |
| category_id         | bigint     | FK                        | Ссылка на категорию товара. ON DELETE SET NULL |

 5. Таблица: cart (Корзина)

| Имя столбца | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                      |
| ----------- | ---------- | ------------------------- | ---------------------------------------------------------- |
| cart_id     | bigint     | PK, NOT NULL              | Уникальный идентификатор корзины                           |
| user_id     | bigint     | FK, UNIQUE, NOT NULL      | Ссылка на владельца корзины (Связь 1:1). ON DELETE CASCADE |

 6. Таблица: product_in_cart (Товары в корзине / Ассоциативная)

| Имя столбца     | Тип данных | Ограничения (Constraints)  | Назначение (Описание)                                                       |
| --------------- | ---------- | -------------------------- | --------------------------------------------------------------------------- |
| product_cart_id | bigint     | PK, NOT NULL               | Уникальный идентификатор записи в корзине                                   |
| cart_id         | bigint     | FK                         | Ссылка на корзину. ON DELETE CASCADE                                        |
| product_id      | bigint     | FK, NOT NULL               | Ссылка на добавленный товар. ON DELETE CASCADE                              |
| amount          | integer    | NOT NULL, DEFAULT 1, CHECK | Количество единиц товара. Проверка: > 0                                     |
| (Table Level)   | -          | UNIQUE                     | Уникальная пара cart_id + product_id (чтобы товар не дублировался строками) |

 7. Таблица: favorit_product (Избранные товары / Ассоциативная)

| Имя столбца    | Тип данных | Ограничения (Constraints) | Назначение (Описание)                       |
| -------------- | ---------- | ------------------------- | ------------------------------------------- |
| fav_product_id | bigint     | PK, NOT NULL              | Уникальный идентификатор записи в избранном |
| user_id        | bigint     | FK                        | Ссылка на пользователя. ON DELETE CASCADE   |
| product_id     | bigint     | FK                        | Ссылка на товар. ON DELETE CASCADE          |
| (Table Level)  | -          | UNIQUE                    | Уникальная пара user_id + product_id        |

 8. Таблица: address (Адреса пользователей)

| Имя столбца        | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                 |
| ------------------ | ---------- | ------------------------- | ----------------------------------------------------- |
| address_id         | bigint     | PK, NOT NULL              | Уникальный идентификатор адреса                       |
| user_id            | bigint     | FK, NOT NULL              | Ссылка на владельца адреса. ON DELETE CASCADE         |
| adress_description | text       | NOT NULL                  | Пользовательское название (например, "Дом", "Работа") |
| city               | text       | NOT NULL                  | Город                                                 |
| street             | text       | NOT NULL                  | Улица                                                 |
| floor              | integer    | NOT NULL, CHECK           | Этаж. Проверка: > 0                                   |
| apartment          | integer    | NOT NULL                  | Номер квартиры / офиса                                |
| (Table Level)      | -          | UNIQUE                    | Запрет на дублирование одинаковых физических адресов  |

9. Таблица: order (Заказы)

| Имя столбца  | Тип данных | Ограничения (Constraints) | Назначение (Описание)                                  |
| ------------ | ---------- | ------------------------- | ------------------------------------------------------ |
| order_id     | bigint     | PK, NOT NULL              | Уникальный идентификатор заказа                        |
| order_number | text       | UNIQUE, NOT NULL          | Публичный номер заказа для клиента (например, "A-123") |
| is_paid      | boolean    | NOT NULL, DEFAULT False   | Статус оплаты заказа                                   |
| order_time   | timestamp  | NOT NULL                  | Дата и время оформления заказа                         |
| finish_price | integer    | NOT NULL, CHECK           | Итоговая сумма заказа (историческая). Проверка: > 0    |
| user_id      | bigint     | FK, NOT NULL              | Ссылка на покупателя. ON DELETE CASCADE                |

 10. Таблица: product_in_order (Товары в заказе / Ассоциативная)

| Имя столбца         | Тип данных | Ограничения (Constraints)  | Назначение (Описание)                                         |
| ------------------- | ---------- | -------------------------- | ------------------------------------------------------------- |
| product_in_order_id | bigint     | PK, NOT NULL               | Уникальный идентификатор позиции в чеке                       |
| order_id            | bigint     | FK, NOT NULL               | Ссылка на заказ. ON DELETE CASCADE                            |
| product_id          | bigint     | FK, NOT NULL               | Ссылка на купленный товар. ON DELETE NO ACTION                |
| amount              | integer    | NOT NULL, DEFAULT 1, CHECK | Количество купленного товара. Проверка: > 0                   |
| order_price         | integer    | NOT NULL, CHECK            | Цена за 1 шт. на момент покупки (историческая). Проверка: > 0 |
| (Table Level)       | -          | UNIQUE                     | Уникальная пара order_id + product_id                         |

 11. Таблица: delivery (Доставка)

| Имя столбца     | Тип данных | Ограничения (Constraints) | Назначение (Описание)                          |
| --------------- | ---------- | ------------------------- | ---------------------------------------------- |
| delivery_id     | bigint     | PK, NOT NULL              | Уникальный идентификатор доставки              |
| tracking_number | text       | UNIQUE                    | Трек-номер для отслеживания курьера/посылки    |
| delivery_date   | timestamp  | NOT NULL                  | Назначенная дата и время доставки              |
| order_id        | bigint     | FK, UNIQUE, NOT NULL      | Ссылка на заказ (Связь 1:1). ON DELETE CASCADE |
| address_id      | bigint     | FK, NOT NULL              | Ссылка на адрес доставки. ON DELETE NO ACTION  |
